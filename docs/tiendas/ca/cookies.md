# Política de galetes de cofounder

**Versió:** 1.0

**Data de la versió:** 10 de novembre de 2026

## 1. Resum

El web https://getcofounder.app **no fa servir galetes** (cookies) ni cap altra tecnologia de seguiment: ni analítica, ni publicitat, ni píxels, ni botons de xarxes socials que et rastregin. Per això no et mostrem cap avís per acceptar-les.

## 2. Què són les galetes

Les galetes són petits fitxers que un web desa al teu navegador per recordar-te entre visites. Hi ha tecnologies semblants, com l'emmagatzematge local del navegador o els píxels de seguiment. La llei obliga a demanar el teu consentiment abans de fer servir les que no són estrictament necessàries per al servei que demanes.

## 3. Què fa servir aquest web

- **Galetes pròpies:** cap.
- **Galetes de tercers:** cap. El web se serveix des de GitHub Pages i no carrega contingut d'altres serveis que posin galetes.
- **Analítica i publicitat:** cap.
- **Emmagatzematge local:** el web públic no desa res al teu navegador.

El servidor que allotja el web (GitHub Pages) rep, com qualsevol servidor, dades tècniques de la connexió, com la teva adreça IP, per poder-te lliurar la pàgina. No les fem servir per seguir-te ni per elaborar perfils.

## 4. L'app

L'app de cofounder per a iOS i Android no fa servir galetes ni porta cap SDK de publicitat ni d'analítica. Si obres la versió web de l'app, la sessió es desa a l'emmagatzematge local del navegador perquè no hagis de tornar a entrar cada vegada. És estrictament necessari per mantenir la sessió que tu inicies, no serveix per seguir-te i el pots esborrar quan vulguis des dels ajustos del navegador (en fer-ho, es tanca la sessió).

## 5. Com esborrar el que desa el teu navegador

Tots els navegadors permeten veure i esborrar les galetes i l'emmagatzematge local de cada lloc des dels seus ajustos de privacitat. Si els esborres, el web públic continua funcionant igual.

## 6. Canvis

Si algun dia afegim galetes o tecnologies que no siguin estrictament necessàries, actualitzarem aquesta política abans i et demanarem el consentiment previ, que podràs rebutjar o retirar.
