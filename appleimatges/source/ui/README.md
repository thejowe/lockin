# Source screens

These PNGs are captures of cofounder’s Expo web build at mobile dimensions. They were rendered from commit `1d0f002c8275d0417d6e4a06c1759f0a89d78ec9` in a temporary checkout using the app’s English interface and an in-memory demo fixture. Each image is 1170 × 2532 pixels, captured at three physical pixels per layout point. The captures include the app content only. Native iOS rendering can differ.

Maya Ellis, Alex Reed, Kit Morgan and June Park are fictional. The project, skills, profiles and conversation are sample data. Maya’s and Alex’s portraits were generated for this campaign.
